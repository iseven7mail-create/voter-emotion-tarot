# 選民情緒塔羅

選舉又到了！新聞各說各話，朋友個個有主見，滑個手機都像在參加辯論大會。你是不是也越看越焦慮、越聽越猶豫，連自己在想什麼都快搞不清楚？

先別急著選邊站，來翻翻「選民情緒塔羅」吧！從 38 張情緒牌卡中，找找此刻最有感的心情，寫下不安，帶走一個做得到的小行動。等心裡的聲音清楚一點，再回頭看看候選人的理念、政見與過往紀錄。

牌卡不幫你算誰會當選，也不告訴你該投誰——只是陪你在熱鬧的選舉裡，找回自己的節奏。🗳️✨

## 內容

- 首頁、隨機翻開三張牌、選牌、寫下不安、選擇小行動與回顧卡。
- 可放大閱讀牌面，並在裝置上產生及下載 PNG 回顧卡。
- 38 張網頁專用 WebP 牌卡，每張均小於 1,000,000 bytes；最大 341,048 bytes。
- 牌卡保持 958 × 1642 原尺寸，整組約 10.4 MB。
- 手機版配置、鍵盤操作焦點與減少動畫偏好。

牌卡用於自我反思，不替使用者決定立場或選票，也不宣稱診斷或療效。書寫內容僅保留於本次瀏覽器操作，下載圖片由裝置產生。

## 檔案

| 路徑 | 用途 |

| `index.html` | 網站入口 |

## 本機預覽

在此資料夾啟動任何靜態網頁伺服器，例如已安裝 Python 時：

```sh
python -m http.server 4173
```

開啟 `http://localhost:4173/`。本網站無需編譯。

## 部署

GitHub Pages 已設定從 `main` 分支的根目錄（`/`）發布。更新網站檔案並提交至 `main` 後，GitHub 會自動重新部署；進度可在專案的 Actions 頁面查看。圖片採用相對路徑，可放在專案網址下。

本儲存庫包含網站程式與網頁版牌卡。高品質原始 PNG 另保留於原工作資料夾的 `highcards/`，不納入公開儲存庫。
