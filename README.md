# 選民情緒塔羅

以 38 張牌整理選舉時的感受，為自己的判斷停一拍。純 HTML、CSS 與 JavaScript，不需要安裝前端框架或連接後端。

[目前正式網站](https://voter-emotion-tarot.i-seven7mail.chatgpt.site/)

## 內容

- 首頁、隨機翻開三張牌、選牌、寫下不安、選擇小行動與回顧卡。
- 可放大閱讀牌面，並在裝置上產生及下載 PNG 回顧卡。
- 38 張網頁專用 WebP 牌卡，每張均小於 1,000,000 bytes；最大 341,048 bytes。
- 牌卡保持 958 × 1642 原尺寸，整組約 10.4 MB。
- 手機版配置、鍵盤操作焦點與減少動畫偏好。

牌卡用於自我反思，不替使用者決定立場或選票，也不宣稱診斷或療效。書寫內容僅保留於本次瀏覽器操作，下載圖片由裝置產生。

## 檔案

| 路徑 | 用途 |
| --- | --- |
| `index.html` | 網站入口 |
| `styles.css` | 桌面與手機版樣式 |
| `app.js` | 抽牌、互動與 PNG 下載 |
| `cards-data.js` | 38 張牌卡的名稱、文字與建議 |
| `cards/` | 網頁專用 WebP 牌卡 |
| `.nojekyll` | 讓 GitHub Pages 直接提供靜態檔案 |

## 本機預覽

在此資料夾啟動任何靜態網頁伺服器，例如已安裝 Python 時：

```sh
python -m http.server 4173
```

開啟 `http://localhost:4173/`。本網站無需編譯。

## 部署

整個資料夾可部署至支援靜態網站的服務。GitHub Pages 可使用 `main` 分支的根目錄，圖片採用相對路徑，可放在專案網址下。

本儲存庫包含網站程式與網頁版牌卡。高品質原始 PNG 另保留於原工作資料夾的 `highcards/`，不納入公開儲存庫。
